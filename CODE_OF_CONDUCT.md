# Code of Conduct

PRV-Lab aims to be a welcoming, respectful, and evidence-driven community.

Examples of expected behavior:

- Be considerate and constructive.
- Critique ideas and results, not people.
- Accept corrections and explain disagreements with evidence.
- Respect privacy and do not publish another person's private information.

Unacceptable behavior includes harassment, personal attacks, discriminatory language, deliberate intimidation, and publishing private information without consent.

Project maintainers may edit, reject, or remove contributions that violate this code and may temporarily or permanently exclude contributors for repeated or severe violations. To report a concern, contact the repository maintainers privately using the contact method listed in the GitHub repository profile. Do not report security vulnerabilities in public issues; follow `SECURITY.md`.
