# PRV-Lab-v0.1.0
EN:
It enables researchers to reproduce privacy curves, compare combinatorial accounting methods, check errors and calculate costs, and derive experimental results that can be used in papers.

Phase I: credible benchmark. Realize the analytic and verifiable Gaussian mechanism benchmark, access the mature PRV accounting implementation, and establish automated testing.

The second stage: fair comparison. Compare the privacy estimation, error bound, running time, calculation budget, fixed parameters and experimental protocol to avoid unfair performance conclusions.

The third stage: forming research results. According to the reproducible results, error authentication, budget allocation, parameter adaptation and more effective benchmark are explored; Only verified improvements can be used as research contributions.

中文：
让研究者能够复现隐私曲线、比较组合会计方法、检查误差与计算成本，并导出可以用于论文的实验结果。

第一阶段：可信基准。实现可解析验证的高斯机制基准，接入成熟的 PRV 会计实现，并建立自动化测试。   

第二阶段：公平比较。对比隐私估计、误差界、运行时间和计算预算，固定参数与实验协议，避免不公平的性能结论。   

第三阶段：形成研究成果。 根据可复现的结果，探索误差认证、预算分配、参数自适应和更有效的基准测试；只有通过验证的改进才作为研究贡献。
